# Changelog

## v0.1.0 — first public release

- Instant regex triage with four risk tiers and deterministic host rules.
- Multi-model review board (five lenses), quorum ladder, per-model circuit breaker, ordered fallback chains.
- Advisor tools: `advisor`, `advisor_panel`, `advisor_debate`.
- SQL blast-radius gate and guard memory that survives sessions.
- Preflight that refuses to half-load; kill switch; `off` / `observe` / `enforce` / `paranoid` modes.
- One-command installer, offline test suite, published benchmark results (including negative ones).
